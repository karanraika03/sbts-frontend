# SBTS Admin Panel

A fresh React + Vite + JSX admin panel starter for **SBTS – Shree Bhanu Technical Solution**.

## Technology
- React 18 + Vite
- JavaScript / JSX (no TypeScript)
- Tailwind CSS v4 via `@tailwindcss/vite`
- React Router
- Lucide React icons
- Recharts for dashboard charts

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Pages included
- Dashboard
- Repair Jobs
- Customers
- WhatsApp
- Parts & Inventory
- Billing & Invoices
- Expenses
- Technicians
- Reports
- Settings

## Important
This is a frontend starter with sample/demo data. It is not connected to ASP.NET Core or SQL Server yet. Add API integration when backend endpoints are ready.
